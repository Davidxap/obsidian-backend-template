# Plugins

Install from Obsidian → Settings → Community plugins.

| Plugin | Needed for |
|---|---|
| **Dataview** | Metrics tables and lists in `Dashboard.md` and the daily template |
| **Tasks** | The "Needs you" block (`📅` due date, `⏫🔼🔽` priority) |
| **Templater** | Daily template. Set *Template folder* = `Human/Templates` and enable *Trigger Templater on new file creation* |
| **Calendar** (optional) | Click a day to open/create its daily note |

Core plugin **Daily notes**: folder `Human/Daily`, template `Human/Templates/Daily`.
