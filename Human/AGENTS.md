# AGENTS.md — Human zone

The user's own notes, exactly as they wrote them. Agents must not summarize, merge or rewrite them.

| Folder | Content |
|---|---|
| `Inbox/` | Unsorted quick capture. Anything uncertain lands here. |
| `Daily/` | One note per day (`YYYY-MM-DD.md`), written by the user. |
| `Projects/` | One note per project. Tasks use Tasks-plugin syntax: `- [ ] task 📅 2026-01-31 ⏫`. |
| `Templates/` | Templater templates. Do not edit without an explicit request. |

## Rules

1. Write here only on explicit request; your own activity log goes to `Machine/Logs/`.
2. Never edit `Daily/` notes: the daily template already embeds the machine log.
3. Every new note gets frontmatter (`type`, `created`) and at least one link to a project or note.
